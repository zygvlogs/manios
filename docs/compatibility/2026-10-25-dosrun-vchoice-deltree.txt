The host root RAMFS was read-only, so the first shared-screen implementation
could not create /dos-screen.bin. The final candidate provisions that one
empty writable RAMFS file at boot; the rest of the root remains read-only.
After that correction, the separate VCLS/VFRAME/VECHO processes' menu was
visible to VCHOICE, and the arrow and digit selection cases passed.

The timeout case remains a known limitation. VCHOICE is therefore Partial;
DELTREE is Working for the workflows listed above. No other compatibility
classification is changed by this evidence.
