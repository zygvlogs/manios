# ManiOS DOS Compatibility Marathon — 191–200

**Test environment:** ManiOS 0.26.1-10252026; QEMU i386, `-cpu 486`, 64 MiB RAM. Each application received a newly formatted, disposable FAT16 disk and was launched through ManiDOS `dosrun`. File outputs were checked with mtools after stopping QEMU where applicable. Third-party archives and disk images stayed under `/tmp`; no application binaries were added to Git.

**Provenance:** Package names, versions and copying policies come from the official FreeDOS 1.4 package listing and each package APPINFO record; the DOS platform declaration was confirmed in all 50 archives. These metadata facts are separate from the test observations below. Untested functionality is explicitly left unverified.
