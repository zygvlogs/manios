Limitations
-----------
  The console is line-oriented. Printable input was delivered with Enter; function, cursor and Alt keys were not used for these game probes.
  Life2 RUN mode needs the PIT channel-0 ports used by BASIC SOUND; the runner currently models only channel 2/PC-speaker ports.
  ShuffleV is LZEXE-compressed; the loader unpacks it and the Turbo Vision screen renders before the unsupported 66h opcode stops it.
  Champ Galagon and Nero 5 fail before a visible screen; the exact VGA/display probe was not isolated further.
  TypeFast uses PCcurses; its screen never became visible on the ManiOS console.
  No application binaries, ZIP archives or disk images are committed.
