<a id="ana015"></a>
### ANA
- **Author / version:** see the package documentation where identified; 0.15 (1990-07-24).
- **Archive:** `ana015.zip` — [msdos/fileutil/ana015.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/ana015.zip); SHA-256 `26ad89fead2e0249e8b25ad2f1c8501a5264943ca19b8d6afb3767494433ee34`.
- **Executable:** `ANA.EXE`.
- **Test command:** `dosrun C:/ANA.EXE --help`.

<a id="carve-20a"></a>
### CARVE
- **Author / version:** see the package documentation where identified; 2.0a (1995-04-22).
- **Archive:** `carve20a.zip` — [msdos/fileutil/carve20a.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/carve20a.zip); SHA-256 `9377472d77016009e13269715a5514ab0f938d2d4c3503e3645536227f8e4a6c`.
- **Executable:** `CARVE.EXE`.
- **Test command:** `dosrun C:/CARVE.EXE /s IN.TXT 1024`.
- **Expected:** Split the 2,500-byte input into 1,024-byte pieces.
- **Observed:** The executor stopped on unsupported AAM before creating any pieces; reconstruction was therefore not possible.

### Bob’s File Dump Program
- **Author / version:** see the package documentation where identified; version unverified (1995 archive).
- **Archive:** `bobdmp10.zip` — [msdos/fileutil/bobdmp10.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/bobdmp10.zip); SHA-256 `b84a356f5510425b6b1c0294b28f3236f492a4dd7fdf2f1a6c093573ee593da6`.
- **Executable:** `DUMP.EXE`.
- **Test command:** `dosrun C:/DUMP.EXE SMALL.TXT`.
- **Expected:** Create SMALL.DMP with a byte-positioned hexadecimal view.
- **Observed:** Host extraction contained the header and one row with bytes `41 42 43 44 0D 0A`, matching the input `ABCD
`.
- **Status:** **Working**.

<a id="comt-010d"></a>
### COMT
- **Author / version:** see the package documentation where identified; 0.10d (1992-08-04 archive).
- **Archive:** `comt010d.zip` — [msdos/fileutil/comt010d.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/comt010d.zip); SHA-256 `0f00eef1ce25c78bb6827ad3d0895eea763eb7a1ae822901c8679a18f6b1e122`.
- **Executable:** `COMT.COM`.
- **Test command:** `dosrun C:/COMT.COM -w HELLO.COM HELLO.ASC; then dosrun C:/COMT.COM -x HELLO.ASC HELLO.COM`.
- **Expected:** Produce a text wrapper, then reconstruct the original COM executable.
- **Observed:** Created the documented HELLO.ASC wrapper. The decoded HELLO.COM was byte-for-byte identical to the source file.
- **Status:** **Working**.

- **Author / version:** see the package documentation where identified; version unverified (1988-03-09 archive).
