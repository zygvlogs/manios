ManiDOS Compatibility Wave 2 — Easy Wins
Test date: 2026-10-24 (Europe/Vilnius)

Environment
- ManiOS 0.26.0-10232026, current local worktree kernel
- QEMU i386, CPU 486, 64 MiB RAM, serial console
- One disposable 8 MiB MBR/FAT16 image per batch, mtools-managed
- Fresh test image held FIND.COM, ATTRIB.COM, DELTREE.COM, MEM.EXE,
  VCHOICE.COM, VCLS.COM, INPUT.TXT, FLAG.TXT, and a nested TREE fixture.
- Original ISO and ZIP files were read-only inputs; no application archive was
  modified. All image and output files stayed under /tmp.

Results

FreeDOS FIND (01Nov2003)
- Ran `FIND.COM "apple" INPUT.TXT`, `FIND.COM /I "apple" INPUT.TXT`, and
  `FIND.COM /V "banana" INPUT.TXT` from the root of the FAT16 volume.
- All three reported `FIND: INPUT.TXT: Cannot open file`; no matching lines
  or search counts were produced. Independently checked that INPUT.TXT exists
  on the image and contains the expected three CRLF lines. Classified Broken.

FreeDOS ATTRIB (BonusCD binary; version unverified)
- `ATTRIB C:/FLAG.TXT` displayed `[----A]`.
- `ATTRIB +R C:/FLAG.TXT` reported `[----A] -> [---RA]`; a following listing
  again displayed `[----A]`. `ATTRIB -R` also reported the original state.
- Independently inspected the FAT directory entry after QEMU exited; it still
  carried only the archive attribute. Reading/listing works, but attribute
  changes are not saved. Classified Partial.

FreeDOS DELTREE (displayed build v1.02g)
- `DELTREE /Y C:/TREE` launched and identified `C:\TREE`, then displayed its
  root-safety warning and interactive confirmation prompt. No confirmation was
  accepted, so deletion and recursive deletion were not verified.
- A follow-up relative `SUB` invocation failed because the DOS runner starts
  each invocation at the drive root (`C:\SUB` was sought). Classified Partial;
  a successful delete remains unverified.

FreeDOS MEM (BonusCD binary; version unverified)
- `MEM.EXE` immediately reported: `The MCB chain is corrupted (no Z MCB after
  last M MCB, but 0 at seg 0x0).` No memory summary was produced. Classified
  Broken.

FreeDOS VCHOICE (BonusCD binary; version unverified)
- `VCHOICE.COM /?` rendered cursor/position control sequences, then reported
  `HELPPATH environment variable is not set.` The ManiDOS shell does not
  implement `set`, so the documented help-path prerequisite could not be
  configured in this test. No menu selection workflow was completed. Classified
  Unsupported pending a valid HELPPATH setup and interactive test.

FreeDOS VCLS (BonusCD binary; version unverified)
- `VCLS.COM` returned, emitting cursor-hide, home, cursor-show and cursor-shape
  control sequences. A QEMU VGA capture after the run still showed the prior
  console contents, so the screen was not cleared. Classified Broken.
- Screenshot: [post-run VGA screen](2026-10-24-wave2-vcls-screen.png).

Reproduction
1. Build a disposable FAT16 image with these six binaries and the fixtures.
2. Boot the local ManiOS kernel in QEMU i386/486 with 64 MiB RAM.
3. Run the commands above from `dosrun`; inspect the FAT16 image afterward with
   mtools. The screen capture is the guest VGA output after VCLS returns.

No compatibility-layer change was made during this batch. No new Working
classification is justified by these results.
