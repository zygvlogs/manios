## Per-program evidence

<a id="u16-v12"></a>
### u16
- **Version / author:** 1.2 (1989); Tom Horsley.
- **Archive:** `u16-v12.zip` — [compress/u16-v12.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/compress/u16-v12.zip); SHA-256 `20fad174392424d05025130c1b524f3ffb1af7699745667208ff493f21a35a96`.
- **Executable:** `U16.EXE`.
- **Test command:** `dosrun C:/U16.EXE -H`.
- **Expected:** Print usage information; core task is decompressing a 16-bit .Z stream to stdout.
- **Observed:** Displayed the version, syntax, 270–280 KB memory note and standard-output behavior. No valid .Z fixture was available, so actual decompression remains unverified.
- **Status:** **Partial**.

<a id="0del-101"></a>
### 0DEL
- **Version / author:** 1.01 (1990-04-21 archive); Peter M. Perchansky.
- **Archive:** `0del-v1.zip` — [dirutil/0del-v1.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/dirutil/0del-v1.zip); SHA-256 `400fd3a6c48f08774efb5f7d884008e9cfbbc7dfb5ac0e423069a35293781b67`.
- **Executable:** `0DEL.EXE`.
- **Test command:** `dosrun C:/0DEL.EXE EMPTY.TXT`.
- **Expected:** Delete zero-length files matching the argument.
- **Observed:** Printed “EMPTY.TXT deleted” and “1 files were deleted”. `mdir` confirmed EMPTY.TXT absent and KEEP.TXT (6 bytes) still present.
- **Status:** **Working**.

<a id="brik-20"></a>
### BRIK
- **Version / author:** 2.0 (1989-07-31 archive); author not identified in inspected package.
- **Archive:** `brik2exe.zip` — [fileutil/brik2exe.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/brik2exe.zip); SHA-256 `45e71543156ab19d7906b75cdc0f99484938d0d874d2c900a226f86e807ff07f`.
- **Executable:** `BRIK.EXE`.
- **Test command:** `dosrun C:/BRIK.EXE -Gb C:/IN.TXT`.
- **Expected:** Print a whole-file binary CRC-32 line.
- **Observed:** Printed a `CRC-32` header and `300446241b c:/in.txt`. Generation completed; independent numerical validation was not established.
- **Status:** **Partial**.

<a id="chksum-2"></a>
### CHKSUM
- **Version / author:** 2 (1989-03-13 archive; package version label unverified); Norman Azadian.
- **Archive:** `chksum2.zip` — [fileutil/chksum2.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/chksum2.zip); SHA-256 `19b1598fbe7c30f9f60a89299a1ac93f0e72f793ff7a6b3d9dfaf4fe6ecaf31c`.
- **Executable:** `CHKSUM.EXE`.
- **Test command:** `dosrun C:/CHKSUM.EXE -v -c C:/CHKSUM.EXE`.
- **Expected:** Verify and report the known checksum and byte count documented in README.
- **Observed:** Output was `56755e1f 11198 C:/CHKSUM.EXE`, matching the independent package README oracle.
- **Status:** **Working**.

<a id="chop-31"></a>
### CHOP
- **Version / author:** 3.1 (1986/1987); Walter J. Kennamer.
- **Archive:** `chop31.zip` — [fileutil/chop31.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/fileutil/chop31.zip); SHA-256 `1e4dccb983a8a79f1d28d0b2c3c0d3e536378f95a505e0812e9a536883642f12`.
- **Executable:** `CHOP31.EXE`.
- **Test command:** `dosrun C:/CHOP31.EXE C:/IN.TXT -P3 -X -Z`.
- **Expected:** Split the supplied file into three exact-byte parts.
- **Observed:** ManiDOS reported unsupported `OUT` on port 03D4 at 15F1:05D7 before completion. Host-side image inspection found no split parts.
- **Status:** **Unsupported**.
