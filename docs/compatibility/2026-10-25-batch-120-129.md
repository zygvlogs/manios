## Per-program records

<a id="cleanse-11"></a>
### CLEANSE
- **Author / version:** W. Parke; 1.1 (1987–1988).
- **Archive:** `cleans11.zip` — [textutil/cleans11.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/textutil/cleans11.zip); SHA-256 `f14cec1e03d06e9b027d27f41b37b0c84560e8d769070dbaed76f8a815182b0b`.
- **Executable:** `CLEANSE.COM`.
- **Test command / interaction:** dosrun C:/CLEANSE.COM IN.TXT OUT.TXT.
- **Expected:** Create a cleaned ASCII output file with standard DOS line endings.
- **Observed:** Reported “File cleansing complete.” Host extraction contained `alpha  CRLF beta line CRLF`; the 0x01 control byte was removed.
- **Status:** **Working**.

<a id="chktxt-200"></a>
### CHKTXT
- **Author / version:** author not identified in inspected README; 2.00 (1992 archive).
- **Archive:** `chktxt.zip` — [textutil/chktxt.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/textutil/chktxt.zip); SHA-256 `4b09c4a195586c2dd6c85af354ea362d5faf11b2fd47634e1b60d9ee9c260012`.
- **Executable:** `CHKTXT.EXE`.
- **Test command / interaction:** dosrun C:/CHKTXT.EXE -f C:/IN.TXT.
- **Expected:** Fix suspicious controls and mixed line endings in place.
- **Observed:** Reported the fixed file usable. Host extraction was `alpha CRLF betaaline CRLF end CRLF 0x1A`; the 0x01 byte was removed and an EOF marker appended.
- **Status:** **Working**.
