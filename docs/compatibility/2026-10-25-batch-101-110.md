# ManiOS DOS compatibility marathon: batch 101–110

- **Test build:** ManiOS 0.26.1-10252026; kernel SHA-256 `cc0a429f6278b2d399e81bbefd45d1185165940e07708d5789e10bafee7275c3`.
- **Environment:** QEMU i386, CPU 486, 64 MiB RAM, ManiOS 0.26.1-10252026, serial console; fresh disposable FAT16 disk image per app; executable copied unchanged and launched through dosrun.
- **Disk handling:** one clone of the 8 MiB FAT16 test image per program; partition offset 1 MiB. Test executables and fixtures stayed outside the repository. Guest networking disabled; QEMU was terminated after each bounded test.
- **Archive source:** [COAST MS-DOS archive](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/). All downloads were listed in the archived SimTel `FILES.IDX` catalog.
- **Common launch:** `cd /n/ata0p1`, then the per-program `dosrun` command below.
- **Shared compression fixture:** 55 bytes, SHA-256 `dea4d9f824116035749129cdaeeb2bb1875911726894821f68972cde53fa3a8b`.

## Per-program evidence

<a id="lzwpc"></a>
### LZWCOM / LZWUNC
- **Version / author:** 1987 SimTel package (version unverified); Kent Williams.
- **Archive:** `lzwpc.zip` — [compress/lzwpc.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/compress/lzwpc.zip); SHA-256 `94b27ea7cec063c60ab71fba958f0b305ad1d355060a13a9cabd785244dc793b`.
- **Executable:** `LZWCOM.EXE / LZWUNC.EXE`.
- **Test command:** `dosrun C:/LZWCOM.EXE C:/IN.TXT C:/OUT.LZW; dosrun C:/LZWUNC.EXE C:/OUT.LZW C:/BACK.TXT`.
- **Expected:** OUT.LZW is created and BACK.TXT restores the original bytes.
- **Observed:** Both executables returned to the shell; OUT.LZW was 62 bytes. BACK.TXT was 55 bytes and byte-for-byte identical to the fixture (SHA-256 dea4d9f824116035749129cdaeeb2bb1875911726894821f68972cde53fa3a8b).
- **Status:** **Working**.

<a id="rle16-sc"></a>
### RLE16
- **Version / author:** 16-bit-header release (1991); Shaun Case.
- **Archive:** `rle16_sc.zip` — [compress/rle16_sc.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/compress/rle16_sc.zip); SHA-256 `8003bec33482541058413cc82183e83bd2098feb78b933f63b99381f32e417a2`.
- **Executable:** `RLE16.EXE / UNRLE16.EXE`.
- **Test command:** `dosrun C:/RLE16.EXE C:/IN.TXT; dosrun C:/UNRLE16.EXE C:/IN.R16`.
- **Expected:** The compressor writes IN.R16 and the uncompressor restores IN.TXT.
- **Observed:** The 63-byte IN.R16 was created. After uncompression, host extraction showed exactly the original 55 bytes (same SHA-256 as the fixture).
- **Status:** **Working**.

<a id="sqpc131"></a>
### SQPC
- **Version / author:** 1.31 (Vernon D. Buerg; 1987-06-25 archive); Vernon D. Buerg.
- **Archive:** `sqpc131.zip` — [compress/sqpc131.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/compress/sqpc131.zip); SHA-256 `f517662ccc0b02f964af38d6f694c94292564e16ecc5a76c15d77c998da87626`.
- **Executable:** `SQPC131.COM / UNSQPC13.COM`.
- **Test command:** `dosrun C:/SQPC131.COM C:/IN.TXT; dosrun C:/UNSQPC13.COM C:/IN.TQT`.
- **Expected:** The input is squeezed to its .TQ* extension and restored by UNSQPC.
- **Observed:** SQPC reported “squeezing, done”; UNSQPC reported “Expanding: IN.TXT”. Host extraction of IN.TXT matched the original 55-byte fixture byte-for-byte (SHA-256 dea4d9f824116035749129cdaeeb2bb1875911726894821f68972cde53fa3a8b).
- **Status:** **Working**.

<a id="addcr-10"></a>
### ADDCR
- **Version / author:** 1.0 (Nathan Fox; archive dated 1994-03-17); Nathan Fox.
- **Archive:** `addcr10.zip` — [textutil/addcr10.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/textutil/addcr10.zip); SHA-256 `ab8106eb8ef707e97acf6835c1fb5efec6ccb2e4b4b54d38fce8a2251ab3f8cc`.
- **Executable:** `ADDCR.EXE`.
- **Test command:** `dosrun C:/ADDCR.EXE C:/IN.TXT`.
- **Expected:** Convert alpha LF beta LF to alpha CRLF beta CRLF only.
- **Observed:** ADDCR reported completion through 100%; host extraction contained alpha CRLF beta CRLF followed by 0xFF. The line conversion occurred, but output differs from the expected two-line fixture.
- **Status:** **Partial**.

<a id="case31"></a>
### CASE
- **Version / author:** 3.1 (1994-09-25); Kevin Krausnick.
- **Archive:** `case31.zip` — [textutil/case31.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/textutil/case31.zip); SHA-256 `20f663b63a9a80d2ac14f85df4acd212a9dc9f1da8bc8161c7ce7e9e7244e60f`.
- **Executable:** `CASE.COM`.
- **Test command:** `dosrun C:/CASE.COM /U C:/IN.TXT C:/OUT.TXT`.
- **Expected:** Write uppercase output while leaving the input intact.
- **Observed:** CASE reported version 3.1 and “Working... 5 words in 2 lines processed.” Host extraction of OUT.TXT was exactly `HELLO OLD WORLD\r\nSECOND LINE\r\n`.
- **Status:** **Working**.

<a id="change17"></a>
### CHANGE
- **Version / author:** 1.7, OzWoz Release 4 (1992); OzWoz Software.
- **Archive:** `change17.zip` — [textutil/change17.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/textutil/change17.zip); SHA-256 `600e4267df266680a65eb1a5abe9a473e70e5f1e9a3377061d6a2731c7a4d34d`.
- **Executable:** `CHANGE.EXE`.
- **Test command:** `dosrun C:/CHANGE.EXE C:/IN.TXT "old" "new"`.
- **Expected:** Replace “old” with “new” in the test file.
- **Observed:** ManiDOS reported “can’t run opcode DF (at 0000:0001)” before CHANGE displayed its own output. Host extraction confirmed IN.TXT was unchanged.
- **Status:** **Unsupported**.

<a id="doscvt-24"></a>
### DOSCVT
- **Version / author:** 2.4 (1993-03-06 archive); Norm Brake.
- **Archive:** `doscvt24.zip` — [textutil/doscvt24.zip](https://ftp.zx.net.nz/pub/archive/ftp.icm.edu.pl/pub/coast/msdos/textutil/doscvt24.zip); SHA-256 `37d80994e07b673a2c25f7d3902a746b3bdf56f18b0479e31b1beb9195eb6df7`.
- **Executable:** `DOSCVT.EXE`.
- **Test command:** `dosrun C:/DOSCVT.EXE -u C:/IN.TXT`.
- **Expected:** Convert DOS CRLF lines to UNIX LF and replace the input file.
- **Observed:** The command returned to ManiOS; the host-extracted file was exactly `alpha\nbeta\n` (11 bytes).
- **Status:** **Working**.
