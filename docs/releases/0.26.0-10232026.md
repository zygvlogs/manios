ManiOS 0.26.0-10232026 is a date-stamped pre-release rebuild of 0.26.0.
It keeps the 0.26.0 DOS EXEC and compatibility work and adds the latest DOS
text-console fix from 2026-10-23. This is a pre-release for i386 PCs, tested
in QEMU.

## What changed

- `dosrun` now implements BIOS `INT 10h AH=06h/07h` scrolling for rectangular
  text windows on the active 80x25 page.
- DOS console output scrolls the active text page when a newline reaches the
  bottom row, instead of overwriting the last line.
- The compatibility database now records 51 programs: 14 Working, 9 Partial,
  28 Broken/unsupported and 0 Untested.
- Zork I (MIT story data, ZIP 2.00) is Working: room text, commands,
  inventory, score, save/restore and quit were verified.
- Adventure (350-point DECUS DOS build) is Working: look, inventory, movement
  and quit were verified.
- The official Infocom Sampler starts and accepts the Planetfall selection,
  but the Planetfall sample text does not render correctly under ZIP/JZIP.
  Full Planetfall remains untested and is not bundled.

## Base 0.26.0 release

This build includes the 0.26.0 DOS EXEC child-process support, DOS
directory/file fixes, video-status polling, PIT channel 2 and PC-speaker
control, and the Windows 1.01 setup progress described in the 0.26.0 release
notes. The Windows desktop still does not run.

## Validation and limits

The release workflow builds with the i686-elf cross toolchain and runs the
repository test suite before publishing. The text-adventure tests were run in
QEMU i386 with a 486 CPU, 64 MiB RAM and a serial console, using fresh FAT16
images.

Zork I still clips the right side of its status line, and a bottom-right black
rectangle remains in the text display. Frotz 2.55/2.53 stop at `OUT 0043h`
(PIT channel 0 control) and DZIP stops at `OUT 00F0h`. JZIP starts the games
but has poor status-line and screen formatting. These are recorded in the
compatibility details.

The Android APK packages the same source snapshot with the Android boot image
using `shell=manide`. It is signed with the existing local upgrade key and is
not a replacement for a physical-device test. No commercial Planetfall story
file, application binaries, ZIP archives or test disk images are included.
