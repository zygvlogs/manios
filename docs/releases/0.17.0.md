ManiOS 0.17.0 brings `grep`, `sed` and 17 more programs from OpenBSD.
ManiOS is an independent operating system for i386 PCs with its own
kernel (ZKT), userland and desktop; see
[0.14.0](https://github.com/zygvlogs/manios/releases/tag/v0.14.0).

This is a **pre-release**, tested in QEMU.

## What's new

- **30 tools from OpenBSD** in `/bin` (11 in 0.16): now also `grep`,
  `sed`, `expr`, `test`, `tail`, `tee`, `tr`, `nl`, `cmp`, `join`,
  `lam`, `fmt`, `column`, `colrm`, `col`, `unexpand`, `tsort`, `vis`
  and `unvis`. OpenBSD's own source, unmodified.

  ```
  manios% ls /bin | grep -c .
  54
  manios% grep -rn Welcome /boot/etc
  /boot/etc/motd:1:Welcome to ManiOS.
  manios% echo hello | sed 's/l*o/0/'
  he0
  manios% ls /bin | grep '^c' | tr a-z A-Z | column
  CAT	CLOCK	CMP	COL	COLRM	COLUMN	COMM	CPU	CPUD	CUT
  manios% expr 4294967296 / 3
  1431655765
  ```

- **Regular expressions** in ManiOS's C library (OpenBSD's, from Henry
  Spencer), and a POSIX layer for programs from elsewhere: `stat`,
  `opendir`/`readdir`, POSIX `open` flags, `getopt_long`, `fts`,
  `asprintf`, 64-bit division on the 386, and more.
- **Smaller programs**: the linker now leaves out unused functions, so
  the programs 0.16 had are smaller than before, though there are 19
  more of them.

## Changed

- Seeking a pipe fails (ESPIPE), as POSIX requires; it used to
  "succeed" without meaning anything.
- `malloc(0)` returns a pointer of its own, as on the BSDs, instead of
  NULL.
- The boot area is 1.2 MiB, so `install` makes a 2 MiB partition.

## Known limits

- ManiOS can't create, rename or remove files yet: `sed -i` and
  `tee FILE` say "read-only file system", and `sort`, `split` and `diff`
  aren't there.
- No floating point in programs: no `printf(1)` or `awk`.
- No signals and no event queue: `tail -f` can't follow a file.
- The "C" locale only: characters are bytes.
- No writable root filesystem; no ^C; ZRP messages are not encrypted;
  BIOS only, PIO disks only.
