ManiOS 0.15.0 brings networking to VirtualBox. ManiOS is an independent
operating system for i386 PCs with its own kernel (ZKT), userland and
desktop; see [0.14.0](https://github.com/zygvlogs/manios/releases/tag/v0.14.0).

This is a **pre-release**, tested in QEMU. VirtualBox reports welcome.

## What's new

- **Network cards.** Besides the NE2000, ManiOS now drives:
  - **AMD PCnet** (PCnet-PCI II, PCnet-FAST III) -- VirtualBox's default
    card for "Other" machines -- as `pcn0`;
  - **Intel PRO/1000** of the 8254x family (82540EM and relatives) --
    VirtualBox's Intel cards, and QEMU's default e1000 -- as `em0`.
- **DHCP.** Without `ip=` on the boot line (or with `ip=dhcp`), ManiOS
  asks a DHCP server for its address, netmask and gateway, and renews
  at half the lease. VirtualBox's NAT, NAT Network and Host-only
  networks answer, and so does QEMU's user network. Until an answer
  comes, the machine uses 10.0.2.15/24 via 10.0.2.2, which is what NAT
  gives anyway. With `ip=` the address is fixed, as before.

In VirtualBox, with the default NAT and the default card:

```
manios% cat /dev/net
lo 127.0.0.1/8 gateway 0.0.0.0
pcn0 10.0.2.15/24 gateway 10.0.2.2 mac 08:00:27:...
manios% exit
ZKT> ping 10.0.2.2
```

For a cluster of ManiOS machines, put them on one VirtualBox "Internal
Network" and give each its own `ip=` and the same `key=`.

## Known limits

- The cards are tested as QEMU emulates them (PCnet-PCI II, 82540EM);
  VirtualBox's FAST III and its two "Server" Intel cards are untested.
  No virtio-net.
- No DNS and no TCP: ManiOS speaks UDP, and ZRP over it, between its
  own machines.
- No writable root filesystem; no ^C; ZRP messages are not encrypted;
  BIOS only, PIO disks only.
