ManiOS 0.24.0 brings **graphical software**: **libui**, a toolkit for
writing it, and the first programs written with it. ManiOS is an
independent operating system for i386 PCs with its own kernel (ZKT),
userland, desktop (ManiDE), disk operating system (ManiDOS) and drivers;
see [0.23.0](https://github.com/zygvlogs/manios/releases/tag/v0.23.0).

ManiDE has had a window system since 0.12, but every program drew its
own pixels and there was little to run in it besides a terminal. Now
there is a way to write graphical programs, a guide to it, and programs
you can use.

This is a **pre-release**, tested in QEMU.

![A calculator and the file browser in ManiDE](https://raw.githubusercontent.com/zygvlogs/manios/v0.24.0/docs/gui/calc-files.png)

## What's new

- **libui**, the widget toolkit: boxes and grids that follow the size
  ManiDE gives a window, labels, buttons, check boxes, one-line entries,
  lists, multi-line text with scroll bars, progress bars, messages, a
  timer, and widgets a program draws and handles itself, in ManiDE's
  look. Integer arithmetic only. The guide:
  [docs/gui.md](https://github.com/zygvlogs/manios/blob/v0.24.0/docs/gui.md);
  the decision: [ADR-0009](https://github.com/zygvlogs/manios/blob/v0.24.0/docs/adr/0009-libui-widget-toolkit.md).
- **`files`**: a file browser. Folders first, sizes, a box to type a path
  in, Enter or a double click to open, Backspace to go up. A file opens in
  **`view`**, a text viewer with line numbers.
- **`calc`**: a calculator. Click it or type; six decimals, eleven digits,
  no floating point. `calc -t` checks its arithmetic.
- **`paint`**: a sketchpad. Sixteen colours, brushes from 1 to 24 pixels, the
  right button erases.
- **`widgets`**: every widget in one window. **`greet`**: the smallest
  graphical program, the guide's first example (34 lines).
- ManiDE's menu (F1) lists **Files**, **Calculator** and **Paint**; the
  run prompt (Alt+d) completes the others. To write a program, put a `.c`
  file in `desktop/apps/`: `make` builds it into `/bin`.

## Changed

- ManiDE's F1 menu has three more entries. Nothing else about the desktop
  changed: its session still opens `fetch`, the welcome, `top` and a terminal.

## Known limits

None of these programs saves: `view` and `files` look, and `paint` keeps
its picture in memory. ManiOS writes FAT volumes since 0.23.0, but libui
has no file chooser or question dialog to pick a volume and a name with,
and no clipboard or menu bar either; Shift+Tab is Tab. Otherwise as
0.23.0: only FAT12 and FAT16; no USB, Intel HD Audio, NVMe or SCSI; no
floating point in programs; no signals. Details:
[M23's notes](https://github.com/zygvlogs/manios/blob/v0.24.0/docs/milestones/M23-gui-software.md#known-limits).
