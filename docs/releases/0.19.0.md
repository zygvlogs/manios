ManiOS 0.19.0 brings **ManiDOS**, a disk operating system of ManiOS's
own: type `dos` and you are at a `C:\>` prompt. ManiOS is an
independent operating system for i386 PCs with its own kernel (ZKT),
userland and desktop (ManiDE); see
[0.18.0](https://github.com/zygvlogs/manios/releases/tag/v0.18.0).

ManiDOS is written for ManiOS from nothing. **It is not MS-DOS, it
contains no MS-DOS code, and it doesn't run MS-DOS** (nor FreeDOS). It
takes from DOS the way of working: drive letters, the commands, batch
files.

This is a **pre-release**, tested in QEMU.

## What's new

- **`dos`** starts ManiDOS; `dos /C COMMAND` runs one command;
  `shell=dos` on the boot command line starts ManiOS in it; and ManiDE's
  F1 menu has it.
- **Drive letters**: A: the boot disk (with `AUTOEXEC.BAT`), C:, D: ...
  the FAT disks, Z: all of ManiOS. `DRIVES` lists them.
- **Commands**: `DIR` (/W /B /P /S), `CD`, `TYPE`, `COPY` (to the
  screen or a device), `VOL`, `CHKDSK`, `TREE`, `FIND`, `SORT`, `MORE`,
  `ECHO`, `SET`, `PATH`, `PROMPT`, `CLS`, `VER`, `MEM`, `DATE`, `TIME`,
  `HELP`, `TRUENAME`, and `|`, `<`, `>` between them.
- **Batch files**: `%1`...`%9`, `SHIFT`, `@`, `ECHO OFF`, `GOTO`,
  `IF ERRORLEVEL / EXIST / ==`, `FOR ... IN (*.TXT) DO`, `CALL`.
- **`CHKDSK`** reads a FAT disk cluster by cluster and finds cross-linked
  files, files longer or shorter than their chains, lost clusters, and
  FAT copies that differ.
- **ManiOS's programs** run from ManiDOS, with DOS paths in their
  arguments turned into ManiOS paths (`grep -c line C:\LONG.TXT`).

## Changed

- ManiOS now needs **7 MiB** of memory (6 MiB until 0.18): its boot image is
  52 KiB bigger, mostly ManiDOS, and it needs 6,022 KiB where QEMU's 6 MiB machine
  has 6,016 free. The loader says both: "ManiOS needs 6 MiB; this
  machine has 6016 KiB".
- The boot message suggests `dos`; `shell=PROGRAM` is a new boot
  option.

## Known limits

ManiOS's drives are read-only, so `DEL`, `REN`, `MD`, `RD` and `COPY`
to a file say "Access denied". ManiDOS runs ManiOS programs and batch
files, not DOS programs (`.COM`, `.EXE`). No dates in `DIR`, no Ctrl+C.
Otherwise as 0.18.0: no floating point in programs; no signals; BIOS
only, PIO disks only.
