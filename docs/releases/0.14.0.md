ManiOS 0.14.0 is the first published release of ManiOS: an independent
operating system for i386 PCs, with its own kernel (**ZKT**, ZygKernel
Technology), its own userland and desktop, and Plan 9's idea that
devices, windows and other machines are all files. It is not a Linux
distribution and contains no GPL code.

This is a **pre-release**: everything below is tested in QEMU (486 CPU
model, SeaBIOS), and nothing yet on real hardware.

## Files

| File | What it is |
|---|---|
| `manios-0.14.0.iso` | The bootable image: a CD image that is also a USB-stick / hard-disk image |
| `manios-0.14.0-kernel.elf` | The ZKT kernel with its symbols (Multiboot 1; for debugging, or `qemu-system-i386 -kernel`) |
| `SHA256SUMS` | Checksums of both |

## Try it

```
qemu-system-i386 -cpu 486 -m 32 -cdrom manios-0.14.0.iso -boot d
```

or write the ISO to a CD, or to a whole USB stick
(`dd if=manios-0.14.0.iso of=/dev/sdX bs=1M`). ManiOS's boot loader
shows the kernel's command line and gives you 3 seconds to edit it
(`sysname=`, `ip=`, `key=`, ...). You land in the shell, `manios% `.

- `ls /bin`, `help` — the programs and the shell's builtins
- `desktop` — the desktop (F1: menu, F2: next window)
- `install ata0` — puts ManiOS on the first IDE disk (asks first; the
  whole disk is erased)

The full guide: [docs/install.md](https://github.com/zygvlogs/manios/blob/v0.14.0/docs/install.md).

## What is in it

- **ZKT**: higher-half i386 kernel, paging and a kernel heap, preemptive
  threads and ring-3 processes, a versioned system call ABI, per-process
  namespaces with union directories, FAT12/16, ATA disks (read and
  write), NE2000 networking with IPv4/UDP, a linear framebuffer.
- **ZRP2**, ManiOS's 9P-style file protocol, with shared-key mutual
  authentication; file servers, CPU servers and terminals from one
  kernel (`mount`, `cpu`, `cpud`).
- **The desktop**: a compositor that serves its windows as files
  (`/dev/wsys`), a panel with a launcher and clock, a terminal, a clock
  and an About window; windows can be drawn by programs on other
  machines.
- **Its own boot loader** (new): MBR, El Torito CD boot and a stage 2
  that reads the memory map, lets you edit the command line from the
  keyboard or a serial line, checks the image's CRC-32, and works with
  LBA or CHS BIOSes. The kernel stays a Multiboot 1 kernel.
- **An installer** (new): `install DISK [KEY=VALUE...]`, run from
  ManiOS itself; the installed disk boots with its own command line and
  can install ManiOS again on another disk. Plus `dd`.

## Fixed in this release

- A job that cannot start on a CPU server (for example because the CPU
  server cannot reach the terminal) now says why on the terminal
  (`cpu: HOST: cannot reach the terminal's namespace (...): ...`) and
  `cpu` exits with 125; before, the reason only appeared on the CPU
  server's console.
- The desktop's terminal keeps the last 256 lines that scrolled off:
  PgUp and PgDn look back; typing or new output returns to the live
  screen.

## Known limits

- Tested only in QEMU. Real 386/486 machines, and BIOSes without the
  LBA extensions (tested only through a build that pretends not to have
  them), are untested.
- No writable root filesystem: an installed system is the live system
  on disk, read-only; FAT volumes are mounted at `/n/ataXpY`.
- No signals: a running program can't be interrupted with ^C.
- ZRP authenticates at attach time only; messages are not encrypted.
- BIOS only (no UEFI); PIO disks only; one NE2000 at I/O 0x300, IRQ 9.
