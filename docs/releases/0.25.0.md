ManiOS 0.25.0 brings **dosrun**, a way to run DOS programs on ManiOS:
an 8086/386 real-mode interpreter with DOS and BIOS services. This is
for the DOS software the user wants to run, including games from a CD.

ManiOS remains an independent operating system for i386 PCs with its own
kernel (ZKT), userland, desktop (ManiDE), disk operating system
(ManiDOS) and drivers; see [0.24.0](https://github.com/zygvlogs/manios/releases/tag/v0.24.0).

This is a **pre-release**, tested in QEMU.

## What's new

- **`dosrun`**, the DOS program runner in `/bin`. It loads a `.COM` or
  `.EXE`, interprets its x86 instructions, and serves `INT 21h` (DOS),
  `INT 10h` (video), `INT 16h` (keyboard), `INT 1Ah` (clock), `INT 2Fh`
  (XMS) and `INT 67h` (EMS).
- **8086 interpreter** in `userland/dosrun/`: ALU, ModR/M addressing
  with segment overrides, shifts/rotates, string instructions with
  `REP`, control flow, stack, interrupts and flags.
- **Common 386 instructions**: `MOVZX`, `MOVSX`, `SETcc`, `BT`/`BTS`/
  `BTR`/`BTC`, `BSF`/`BSR`, `CMOVcc`, `XADD`, `CMPXCHG`, `BSWAP`,
  `CPUID`, `SHLD`/`SHRD`, and the two-byte `Jcc`. The interpreter stays
  16-bit, so protected mode and DOS extenders are still out.
- **XMS** (`INT 2Fh` AH=43h): allocate, resize and free extended-memory
  handles, and move data between conventional memory and extended
  memory. Pool size is 8 MiB by default.
- **EMS** (`INT 67h`): allocate pages, get the page-frame segment, map
  logical pages into the 64 KiB frame, save and restore the page map.
  Pool size is 4 MiB by default.
- **`.COM` and `.EXE` loader**: the classic PSP at 0x100 for `.COM`,
  the MZ header and relocation table for `.EXE`.
- **Drive mapping**: DOS paths map onto ManiOS paths with the same
  scheme ManiDOS uses, so `dosrun` and ManiDOS see the same files.
- **Mode 13h**: a graphical DOS program's framebuffer at physical
  `0xA0000` is copied to ManiOS's VGA mode 13h screen.
- **The decision**: [ADR-0010](https://github.com/zygvlogs/manios/blob/v0.25.0/docs/adr/0010-running-dos-programs.md) records why DOSBox, FreeDOS and
  MS-DOS binaries were rejected, and that a native emulator is the path.
- **The guide**: [docs/dosrun.md](https://github.com/zygvlogs/manios/blob/v0.25.0/docs/dosrun.md) describes what runs and what doesn't.
- **The milestone**: [docs/milestones/M24-dosrun.md](https://github.com/zygvlogs/manios/blob/v0.25.0/docs/milestones/M24-dosrun.md).

## Changed

- Nothing in the kernel, desktop, or ManiDOS changed. `dosrun` is a new
  userspace program.

## Known limits

- No protected mode, no DOS extenders, no 32-bit segmented memory.
- No sound (Sound Blaster, AdLib, PC speaker), no mouse, no serial,
  no joystick.
- No TSRs, no child processes (`INT 21h` AH=4Bh `EXEC` is absent).
- No networking from DOS programs.
- Only one DOS program at a time; `dosrun` returns to the shell when
  it ends.
- EMS and XMS pools are fixed at compile time.
