# ManiOS 0.26.1-10252026

This maintenance release completes the shared DOS text-screen path introduced
for the FreeDOS utility workflows.

- DOS console string writes now update the emulated B800 text cells, so a
  later DOS process can read the text drawn by earlier VCLS, VFRAME and VECHO
  processes.
- The kernel provisions one empty writable `/dos-screen.bin` file in RAMFS
  for the screen state shared between `dosrun` processes. Other root paths
  remain read-only.
- DOS Enter input is normalized to carriage return, as DOS programs expect.
- The DOS host harness keeps raw stdout behavior; screen teletype output is
  enabled only in ManiOS builds.
- FreeDOS DELTREE passed six disposable-image cases covering deletion,
  cancellation, root safety and missing targets. VCHOICE help, arrow selection,
  digit selection and Escape passed; timeout-to-default remains unverified
  and is marked Partial in the compatibility matrix.

The Android package embeds the same ManiOS system image. The website archive
contains the updated downloads and compatibility page.


Verification and packages

- `make -j2 test` passed, including boot, installer, console, network, graphics,
  desktop, GUI, DOS guest, driver and cluster suites.
- The signed Android APK verifies with APK signature schemes v1, v2 and v3; its
  embedded ISO matches the standalone Android ISO byte for byte.
- The website bundle is a deployable static archive.
