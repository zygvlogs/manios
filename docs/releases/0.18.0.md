ManiOS 0.18.0 brings **ManiDE**, ManiOS's desktop made over into a
tiling desktop. ManiOS is an independent operating system for i386 PCs
with its own kernel (ZKT), userland and desktop; see
[0.17.1](https://github.com/zygvlogs/manios/releases/tag/v0.17.1) for
what came before.

This is a **pre-release**, tested in QEMU.

![ManiDE](https://raw.githubusercontent.com/zygvlogs/manios/v0.18.0/docs/desktop/screenshot.png)

## What's new

- **ManiDE.** Type `manide` (or `desktop`, as before). Windows tile the
  screen in panes — a grid, a tall master-and-stack, or one at a time —
  on nine workspaces, under a status bar with the host, kernel, uptime,
  CPU, memory, network and time. It opens with `fetch`, a welcome, `top`
  and a terminal (`/boot/etc/manide` lists them).

  | Keys | |
  |---|---|
  | Alt+Enter | a terminal |
  | Alt+d | run a program (Tab completes) |
  | Alt+1 … 9 | show a workspace |
  | Alt+Shift+1 … 9 | move the window there |
  | Alt+j / Alt+k | the next / previous window |
  | Alt+Space | the next layout |
  | Alt+q | close the window |
  | Alt+Shift+Q | exit ManiDE |
  | F1 | the menu |

  The mouse focuses panes, closes them from their title strips, and
  picks workspaces from the bar.
- **`fetch`** shows the system at a glance, beside the ManiOS logo, and
  **`top`** the processes, busiest first, with CPU and memory bars
  (`top -b` for plain text). Both work in ManiDE's terminal and on the
  text console, which now shows colours.
- **The terminal** is as large as its pane, and understands the ANSI
  escape sequences full-screen programs use.
- **New in the kernel:** `/dev/sysstat` (uptime, idle time, memory, the
  CPU) and `/dev/ps` (every process, with its CPU time and memory); the
  Alt key; bigger transfers to file servers, which made the desktop
  much faster to draw.
- `cat` and `dd` end quietly when the program reading from them has
  gone (`yes | cat | head`), as the stdio programs have since 0.17.1.

## Changed

- Windows no longer choose their size or place: ManiDE tiles them and
  tells each its size, and a program redraws at it (`libwin` does the
  telling for you). `/dev/wsys/N/ctl` lost `move` and gained `size W H`
  and `ws N`. See [ADR-0007](https://github.com/zygvlogs/manios/blob/v0.18.0/docs/adr/0007-manide-tiling-desktop.md).
- The boot area is 1.3 MiB (`install` still makes a 2 MiB partition).

## Known limits

As 0.17.1: ManiOS can't create, rename or remove files yet; no floating
point in programs; no signals; the "C" locale only; BIOS only, PIO disks
only. ManiDE needs a display adapter with the Bochs VBE registers
(QEMU's standard one, VirtualBox's, VMware's SVGA II), 640×480 or more;
it runs its session comfortably in 32 MiB. The terminal has no raw key
mode yet (`top` quits on q and Enter).
