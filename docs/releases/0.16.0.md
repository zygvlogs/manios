ManiOS 0.16.0 brings the first programs from BSD: text tools from
OpenBSD. ManiOS is an independent operating system for i386 PCs with its
own kernel (ZKT), userland and desktop; see
[0.14.0](https://github.com/zygvlogs/manios/releases/tag/v0.14.0).

This is a **pre-release**, tested in QEMU.

## What's new

- **Tools from OpenBSD** in `/bin`: `head`, `cut`, `paste`, `comm`,
  `uniq`, `rev`, `fold`, `expand`, `basename`, `dirname` and `yes`.
  They are OpenBSD's own source, unmodified, built against ManiOS's C
  library; they behave, and word their messages, as on OpenBSD.

  ```
  manios% ls /bin | head -n 3
  about
  basename
  bind
  manios% cat /dev/net | cut -d ' ' -f 1,2
  lo 127.0.0.1/8
  manios% echo ManiOS | rev
  SOinaM
  ```

- **ManiOS's libc speaks more POSIX and BSD**, for programs from
  elsewhere: `getopt`, `err`/`warn`, `getline`, `strtoll`/`strtoull`,
  `strtonum`, `reallocarray`, `strsep`, `strcasecmp`, `basename`,
  `dirname`, `freopen`, `isblank`, `getprogname`, and the headers such
  programs include (`<unistd.h>`, `<err.h>`, `<libgen.h>`, ...).
- **Pipes end like on Unix.** ManiOS has no signals; now a program whose
  output goes to a pipe nobody reads any more ends by itself (status
  141, as SIGPIPE would), so `yes | head` finishes.
- **License notices ship with the system.** `cat /boot/etc/notices`
  shows the copyright notice and license of every imported file, and
  each release carries them as `NOTICES.txt`. The imports are recorded
  in [third_party/THIRD_PARTY_NOTICES.md](https://github.com/zygvlogs/manios/blob/v0.16.0/third_party/THIRD_PARTY_NOTICES.md).

## Fixed

- **A rare lost frame on AMD PCnet cards.** In QEMU, about one received
  frame in 12,000 was dropped: QEMU hands a receive descriptor back
  before it has finished writing it, and the driver took the half-written
  descriptor for a malformed frame. The driver now waits for the rest.
  (Whether VirtualBox's PCnet does the same is not known; on a card that
  doesn't, nothing changes.)

## Known limits

- The "C" locale only: characters are bytes.
- Not imported yet: tools that need regular expressions (`grep`, `sed`,
  `nl`), signals (`tee`) or creating files -- ManiOS can't create files
  yet.
- No writable root filesystem; no ^C; ZRP messages are not encrypted;
  BIOS only, PIO disks only.
