ManiOS 0.26.0-10252026 is a date-stamped pre-release rebuild of 0.26.0.
It extends the DOS runtime and compatibility work from 0.26.0, with an
emphasis on text-mode applications, keyboard input, files and timer-driven
programs. This release is for i386 PCs and has been tested in QEMU.

## What changed

- DOS programs can receive PS/2 keyboard input, including cursor, navigation
  and function keys through the BIOS keyboard buffer.
- BIOS text services now cover mode and page resets, text-page switching,
  cursor visibility and shape, rectangular scrolling, and initialized BIOS
  video data. The VGA console defers wrapping at the bottom-right cell so
  direct DOS screen redraws do not scroll behind the guest's display cache.
- `dosrun` delivers PIT channel 0 IRQs through the guest's interrupt vector,
  with master PIC masking, edge latching, EOI handling and chainable BIOS
  INT 08h / INT 1Ch handlers.
- DOS file compatibility now includes repeat FCB close, MCB list-of-lists,
  file attributes backed by FAT directory entries, and signed seek offsets.
- The compatibility records document tested workflows for VisiCalc,
  Directory Freedom, EDITV, SemWare TSE, VIEW, Life2 and FreeDOS utilities.
  Working means the listed workflow passed; it does not claim complete
  application compatibility.

## Validation and limits

The release workflow builds ManiOS and runs the full repository test suite.
DOS application checks used QEMU i386 with a 486 CPU and disposable FAT16
images. The evidence and known limitations are in
[`docs/compatibility/details.md`](../compatibility/details.md) and the linked
test records.

ManiOS has been tested in emulators, not on physical PCs. Life2 patterns and
many broader DOS application features remain untested. The Android package
uses the same ManiOS system image under Limbo/QEMU; package boot testing does
not replace a physical Android device test.
