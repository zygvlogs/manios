# ManiOS 0.27.0-10252026 — development prerelease

## October 28 correctness update

Nineteen shared CPU and DOS/BIOS defect groups were corrected, including shift/bit/arithmetic flags, division faults, handle reuse, elapsed time, executable paths, IOCTL, BIOS memory reporting, fast console output and initial EXE memory allocation. The full build/test gate passes.

The catalogue now contains **83 Working, 27 Partial, 12 Broken, 63 Unsupported and 15 Untested** entries. Twenty-two entries were freshly exercised; the remaining 178 retain historical evidence. Missing SMSW/control state, x87, protected mode/DPMI, VGA CRTC and several DOS reporting services remain limits. See the [engineering report](../compatibility/2026-10-27-bugfix-audit.md) for evidence and classification corrections.

## October 25 snapshot (historical)


This compatibility update adds a tested subset of real-mode 32-bit operands
through the x86 `66h` prefix. It is an ongoing development build.

The interpreter preserves complete EAX–EDI values while keeping its existing
16-bit DOS/BIOS service interface. Supported dword forms include MOV,
ADD/ADC/SUB/SBB/CMP, AND/OR/XOR/TEST, INC/DEC/NOT/NEG, XCHG, LEA,
PUSH/POP, CWDE/CDQ, MOVZX/MOVSX, BSWAP and MOVSD/STOSD/LODSD
with REP and 16-bit address/count registers. CPUID now uses full registers,
returns the complete vendor leaf and advertises no unimplemented features.
Nested DOS EXEC initializes child upper registers and restores parent state.

The decoder retains 16-bit addresses and stack addressing, validates the
supported instruction lengths and memory forms, and explicitly refuses other
prefixed operations. New fault diagnostics include the instruction bytes.
32-bit control transfers, shifts, comparing strings, multiply/divide, protected mode,
DPMI, x87 and address-size override remain outside this subset. See
[the exact CPU contract](../dosrun.md#real-mode-operand-size-override-0270-development).

The paint GUI regression now waits for the page and palette to arrive in
the streamed first frame. It retains exact color assertions. Deterministic
coverage reproduces the partial-frame interleaving and checks that a
permanently wrong palette still fails.

CPU coverage compares 32,768 arithmetic/flag cases against native x86,
with address/undefined-behavior sanitizers, plus ModR/M, segment, mixed-width,
stack, CPUID, instruction-length and explicit-fault checks. A FAT16 COM
regression exercises 32-bit operations across the DOS INT 21h service.
Existing AAM, INTO and guest-visible DOS/BIOS interrupt gateways are retained.

Application retest observations and final regression evidence are recorded
in [the update report](../compatibility/2026-10-25-operand32-retests.md).
[Future architecture notes](../compatibility/0.27.0-future-architecture.md)
cover DPMI, x87/FWAIT and the remaining hardware-port work.

Final verification completed successfully: `make -j4`, `make test -j4`,
focused CPU/EXEC/AAM/INTO checks, DOS/BIOS guest checks and GUI paint checks.
The database remains at 200 entries: 80 Working, 25 Partial, 14 Broken,
66 Unsupported and 15 Untested. Retested applications have updated evidence
and unchanged statuses. No unresolved regression-test failures remain.
