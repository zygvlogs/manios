ManiOS 0.14.1 makes the first boot friendlier and adds VirtualBox's
display adapters. ManiOS is an independent operating system for i386
PCs with its own kernel (ZKT), userland and desktop; see
[0.14.0](https://github.com/zygvlogs/manios/releases/tag/v0.14.0) for
what it is.

This is a **pre-release**: tested in QEMU, and seen booting in
VirtualBox; not yet on real hardware.

## What changed

- **A quiet boot screen.** ManiOS still tests itself at every boot, but
  the screen now shows one line of what it checks instead of the whole
  log:

  ```
  ManiOS 0.14.1 / ZKT (ZygKernel Technology)
  Self-tests: memory, interrupts, threads, devices, disks, files, programs,
              C library, network, graphics, windows, cluster. All passed.
  ManiOS 0.14.1 is ready. Try ls /bin (programs), help (the shell), desktop.
  manios%
  ```

  The full log -- including the test programs that crash on purpose to
  check that ManiOS survives them, which looked like errors -- always
  goes to the serial port, and to the screen too with the boot option
  `verbose=1`. A failing check still stops the boot with its message on
  the screen.
- **Plainer boot loader messages.** "Boot options: (none) / Press any
  key within 3 seconds to change them."; and when editing, "Type the
  boot options, then press Enter to start ManiOS."
- **VirtualBox's and VMware's display adapters.** The desktop and
  `gfxdemo` now find VirtualBox's graphics controllers (VBoxVGA,
  VMSVGA, VBoxSVGA) and VMware's SVGA II, not only QEMU's and Bochs's.
  VMSVGA / SVGA II is tested (through QEMU's `-vga vmware`); VBoxVGA and
  VBoxSVGA are untested -- if `desktop` finds no framebuffer, switch the
  VM to VMSVGA.

## Files

| File | What it is |

| `manios-0.14.1.iso` | The bootable image: a CD image that is also a USB-stick / hard-disk image |

| `SHA256SUMS` | Checksums of both |

Guide: [docs/install.md](https://github.com/zygvlogs/manios/blob/v0.14.1/docs/install.md).

## Known limits

As in 0.14.0: no network in VirtualBox (ManiOS knows only the NE2000,
which VirtualBox doesn't offer); no writable root filesystem; no ^C; ZRP
messages are not encrypted; BIOS only, PIO disks only.
